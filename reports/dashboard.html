Star Schema Dimensional Architecture

Central Fact: Fact_StudentPerformance
Grain: One record per student per course per exam session.
Conformed Dimensions: Dim_Student, Dim_Course, Dim_Faculty, Dim_AcademicTime.
Key Advantage: Single-hop star joins reduce CPU and I/O latency, perfect for enterprise OLAP reporting.

Snowflake Schema Comparison

Normalized Hierarchies:
Dim_College → Dim_Department → Dim_Course / Dim_Faculty.
Key Advantage: 3NF normalization eliminates redundancy.
Trade-Off: Multi-level relational joins introduce measurable query latency overhead for complex aggregations.
